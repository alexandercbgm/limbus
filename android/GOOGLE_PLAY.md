# Limbus в Google Play

Всё, что нужно для Play Console: что загружать, что отвечать в анкетах, тексты и картинки страницы.

## Главное

| Поле | Значение |
|---|---|
| Название пакета (Package name) | `io.github.alexandercbgm.limbus` |
| Файл для загрузки | `android/limbus.aab` (Android App Bundle) |
| Версия | versionCode `1`, versionName `1.0` |
| Минимальный Android | 7.0 (API 24) |
| Целевой Android | 16 (API 36) |
| Разрешения | только для покупок: оплата через Google Play, интернет (их добавляет библиотека Google Play Billing) |
| Ориентация | только горизонтальная |
| Цена | бесплатно, без рекламы; одна необязательная покупка — кристаллы для Арсенала |
| Политика конфиденциальности | <https://alexandercbgm.github.io/limbus/privacy.html> |

Название пакета нельзя поменять после первой загрузки: это навсегда «паспорт» приложения в Google Play.

**Покупка — через Google Play.** Google разрешает продавать внутриигровое (кристаллы) только через свою платёжную систему, поэтому в версии для Play станция Emptio продаёт один набор, как в вебе за $3, но кнопка «Купить в Google Play» открывает обычное окно оплаты Google. Кода нет: кристаллы приходят сразу после оплаты. Это делает `play-src/PlayBilling.java` (библиотека Google Play Billing 8.3), сборку ведёт Gradle (`play-gradle/`).

### Товар в консоли — создайте до первой проверки покупки

Сначала загрузите AAB хотя бы в закрытое тестирование (без загруженной сборки с разрешением на покупки раздел товаров недоступен) и заполните платёжный профиль продавца (Монетизация → Настройка монетизации; для продажи нужен профиль продавца в Google Payments).

Монетизация → Товары → **Встроенные товары** (One-time products) → Создать:

| Поле | Значение |
|---|---|
| Идентификатор товара (Product ID) | `crystals_everything` — ровно так, игра ищет его по этому имени |
| Название | Всё сразу — 1345 кристаллов |
| Описание | Вход на склад, все пушки (кроме Ferrum) и все улучшения до третьего уровня +25% бонус. |
| Цена | на ваш выбор, например эквивалент $2.99; Google сам пересчитает в валюты стран |
| Тип | разовая покупка; игра сама «расходует» её после зачисления, так что купить можно повторно |

Активируйте товар. Пока его нет или он неактивен, кнопка в игре будет неактивной.

Проверять покупки удобно без денег: Настройка → **Тестирование лицензий** → добавьте свой аккаунт Google. Тестовые покупки с него не списывают деньги.

## Ключ загрузки — сохраните его

`android/upload.jks` и пароль к нему в `android/upload.properties`. Этим ключом подписывается каждый файл, который вы загружаете в Play. В git их нет: **сохраните оба файла в надёжном месте** (менеджер паролей, облако). Если ключ потерять, новый можно получить только через поддержку Google, и это занимает дни.

При создании приложения оставьте **Play App Signing** (подпись приложения в Google Play) включённой — так Google хранит главный ключ сам, а ваш ключ — только для загрузки.

### Рейтинг контента (анкета IARC)

- Категория: **Игра** (All other app types → Game).
- Насилие: в игре стреляют стальными шарами по стеклу и предметам, а в части уровней сбивают абстрактных «стражей-теней» и «бесов-кристаллов» — без крови, без людей и реалистичных существ. Честный ответ: **есть фантастическое/мультяшное насилие по отношению к нереалистичным персонажам**, без крови и жестокости.
- Страх, секс, нецензурная лексика, наркотики, алкоголь, азартные игры: **нет**.
- Общение пользователей, обмен контентом, местоположение: **нет**.
- Цифровые покупки: **да** (кристаллы за деньги через Google Play; лутбоксов и случайных наград нет).

Ожидаемый результат — минимальный или почти минимальный рейтинг (например, PEGI 3 или 7, ESRB Everyone).

### Безопасность данных (Data safety)

Сама игра ничего не собирает: прогресс хранится только на устройстве. Покупки проводит библиотека Google Play Billing, она общается с серверами Google. Осторожный (безопасный для проверки) вариант ответов:

- Собирает ли приложение данные? **Да.**
- Шифруются ли данные при передаче? **Да.**
- Можно ли запросить удаление данных? **Нет** (данные о покупках хранит Google).
- Типы данных: **Финансовая информация → История покупок** — собирается, не передаётся третьим лицам, обязательна, цель: **функциональность приложения**.

Сверьтесь с актуальной справкой Google по Play Billing Library и разделу «Безопасность данных»: Google иногда уточняет, что нужно указывать для собственных библиотек.

## 5. Тестирование и выпуск

**Если аккаунт разработчика личный и создан после ноября 2023 года**, Google сначала требует **закрытое тестирование: не меньше 12 тестировщиков, которые 14 дней подряд держат приложение установленным**. Только потом откроется доступ к рабочей версии (Production). Для аккаунта организации этого требования нет.

1. Тестирование → **Закрытое тестирование** → создайте трек, добавьте список тестировщиков (их адреса Google).
2. **Создать выпуск** → загрузите `android/limbus.aab`.
3. Название выпуска: `1 (1.0)`. Примечания к выпуску:
   ```
   <ru-RU>
   Первый выпуск Limbus.
   </ru-RU>
   <en-US>
   The first release of Limbus.
   </en-US>
   ```
4. Отправьте на проверку. Первая проверка обычно занимает от нескольких часов до нескольких дней.
5. Через 14 дней с 12 тестировщиками — **Рабочая версия** → создать выпуск из того же файла (или нового) → страны: все.

## Обновления

Каждый новый файл в Play должен иметь versionCode больше прежнего:

```
VERSION_CODE=2 VERSION_NAME=1.1 ANDROID_HOME=… android/build_aab.sh
```

Скрипт соберёт его Gradle (нужны `ANDROID_HOME` с `platforms;android-36`, JDK и Gradle) и подпишет ключом из `android/upload.jks`.
