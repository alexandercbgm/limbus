# Бот Limbus на Cloudflare Workers

`worker.js` — сервер бота:

- **`/start` и `/play`** — приветствие с роликом случайного уровня и кнопка «Играть»; человек записывается в рассылку. Ссылка `t.me/бот?start=nox` приветствует роликом этого уровня, и «Играть» открывает его. До нажатия «Старт» пустой чат показывает описание бота; его задаёт ссылка настройки (шаг 7).
- **Язык.** Бот говорит по-русски с теми, у кого Telegram на русском (а также украинском, белорусском, казахском), с остальными — по-английски. **`/language`** — выбрать язык вручную; выбор запоминается.
- `/stop` — отписка от рассылки (в меню команд её нет).
- **`/support` или любое сообщение** — пересылается вам. Вы отвечаете на пересланное сообщение (Reply), и ответ уходит игроку от имени бота. Проверить на себе: отправьте `/support`, затем сообщение — оно придёт вам как от игрока, и на него можно ответить.
- **Кристаллы за звёзды Telegram** (станция Emptio в игре):
  - **в Telegram** — игра сама открывает окно оплаты набора и после оплаты добавляет кристаллы;
  - **в APK и браузере** — кнопка ведёт в бота, бот продаёт один набор «Всё сразу» и присылает код, его вводят в игре.
  - **`/buy`** открывает игру сразу на станции Emptio.
- **`/broadcast уровень текст`** (только вам) — каждому подписчику на его языке уходит ролик уровня (или его картинка), текст и кнопка «Играть», которая открывает именно этот уровень. Вспомогательные команды: `/stats` — число пользователей и ход рассылки, `/cancel` — остановить рассылку.

Всё бесплатно. Банковская карта не нужна.

## Настройка (один раз, ~10 минут)

1. **Аккаунт.** Зарегистрируйтесь на <https://dash.cloudflare.com/sign-up> по почте.

2. **Worker.** Слева откройте **Compute (Workers) → Workers & Pages → Create → Create Worker** (в некоторых версиях кабинета — **Start with Hello World**). Название — например, `limbus-bot`. Нажмите **Deploy**.

3. **Код.** Нажмите **Edit code**. Удалите всё в файле `worker.js` слева и вставьте содержимое [`bot/worker.js`](worker.js) из репозитория целиком. Нажмите **Deploy**.

4. **Хранилище (KV).** Слева откройте **Storage & Databases → KV → Create** и назовите хранилище `limbus-users`. Затем вернитесь в Worker и откройте **Settings → Bindings → Add → KV namespace**:
   - Variable name: **`USERS`** (ровно так, заглавными);
   - KV namespace: `limbus-users`.

5. **Переменные.** В Worker откройте **Settings → Variables and Secrets → Add** и добавьте четыре строки:

   | Тип | Имя | Значение |
   |---|---|---|
   | Secret | `BOT_TOKEN` | токен бота из @BotFather |
   | Secret | `WEBHOOK_SECRET` | любое длинное слово из латинских букв и цифр, например `limbus7f3k9q2xw8` — придумайте своё |
   | Text | `OWNER_ID` | ваш числовой Telegram ID (его покажет @userinfobot) |
   | Text | `GAME_URL` | `https://alexandercbgm.github.io/limbus/` |

   Нажмите **Deploy**.

6. **Расписание для рассылки.** Бесплатный Worker отправляет за раз около 45 сообщений, остальное досылается раз в минуту. В Worker откройте **Settings → Trigger Events (Triggers) → Add → Cron Triggers** и укажите расписание `* * * * *` (каждую минуту).

7. **Подключение к Телеграму.** Скопируйте адрес Worker'а (вида `https://limbus-bot.ВАШЕ-ИМЯ.workers.dev`) и откройте в браузере:
   ```
   https://limbus-bot.ВАШЕ-ИМЯ.workers.dev/setup?key=ВАШ_WEBHOOK_SECRET
   ```
   Должен прийти ответ, в котором у каждого пункта `"ok":true`. Эта ссылка подключает бота к Worker'у, задаёт меню команд (`/play`, `/buy`, `/support`, `/language`; по-английски по умолчанию, по-русски для русскоязычных), описание бота и кнопку «Играть».

8. **Проверка.** Напишите боту `/start` — должна прийти кнопка «Играть». Затем отправьте боту любое сообщение с другого аккаунта: оно должно прийти вам.

9. **Адрес — мне.** Пришлите адрес Worker'а. Я впишу его в игру (`telegram/bot-api.txt`), чтобы Телеграм-версия сообщала боту, кто играет. Тогда в рассылку попадут и те, кто ни разу не писал боту, но разрешил сообщения в игре.

## Рассылка

Напишите боту (только с вашего аккаунта):
```
/broadcast rubinus Новый уровень уже на линии!
```
Уровни: `initium thesaurus vitrum rubinus labyrinthus hortus speculum tao nox carcer lux` (Nox можно назвать и `abyssus`).
В сообщении будет ролик уровня, видео 16:9 без звука; если ролик не отправится — миниатюра. Кнопка «Играть» откроет карточку уровня.

Рассылайте не чаще раза в неделю и по делу: на частые рассылки люди жалуются, и Телеграм может ограничить бота.

## Важно

- Токен бота храните только в Cloudflare (секрет `BOT_TOKEN`). Никому его не присылайте, в том числе в чат.
- Если токен утёк: в @BotFather выполните `/revoke`, затем вставьте новый токен в `BOT_TOKEN`.
- Пока бот не был подключён, Телеграм хранил входящие сообщения около суток. При подключении они придут на сервер, и авторы этих сообщений попадут в список. Более ранних пользователей восстановить нельзя.
